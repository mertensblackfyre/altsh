altsh
============
altsh is a lightweight command-line interface

Features

* redirection of stdout & stderr
* stores command history

Dependencies
-----------
* gcc
* cmake
* readline

Installation
-----------
```
git clone https://github.com/mertensblackfyre/altsh.git
cd altsh
mkdir build
cd build
cmake ..
make
```

Usage
-----------
```
./altsh
```
